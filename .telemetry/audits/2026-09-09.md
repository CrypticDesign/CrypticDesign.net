## Observed Patterns

- **Naming style:** snake_case throughout the nine-event contract.
- **Naming format:** GA4-compatible action and outcome names.
- **Centralization:** event types and sanitization live in `src/lib/analytics.ts`; browser dispatch lives in `src/lib/analytics-client.ts`.
- **Error handling:** calls are synchronous and non-blocking; ineligible environments and absent tag state return without delivery.
- **Blocking calls:** none.

## Hygiene Notes

1. All nine event definitions have at least one verified call path.
2. Event properties are allowlisted and sanitized before dispatch.
3. Names, emails, account/member/Character IDs, form contents, tokens, payment/order data, arbitrary query values, and replay data are excluded by the implementation contract.
4. Tag loading is consent-gated and restricted to production builds on canonical hosts.
5. The queue stub uses rest-parameter arrays, while Google's documented browser bootstrap queues the function `arguments` object.
6. The 2026-09-09 production diagnostic found the correct tag and destination in Google Tag Assistant, which reported deferred hits and no transmitted hits.
